# All In One - Local Service Directory

A modern, responsive local service directory website where users can find contact phone numbers for plumbers, electricians, Wi-Fi technicians, truck drivers/movers, and more. 

## Features
- **Live Search Filtering:** Instantly find services by typing keywords.
- **Direct Phone Integration:** Click-to-call links (`tel:`) for quick dialing on mobile devices.
- **Dynamic Business Registration:** Local service providers can submit their numbers directly through the form on the website (stored locally in browser storage).
- **Admin Delete Controls:** Easily remove any listing right from the UI.

## How to use / Deploy
1. Upload these files to your GitHub repository.
2. Enable **GitHub Pages** in your repository settings (point it to the `main` branch or root folder) to publish your website for free!
